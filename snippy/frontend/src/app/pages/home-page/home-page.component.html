Inside a snippet

The editor, the preview, and the way you share it all live on the same snippet.

  1. Preview

    It updates as you type

    The preview sits with the source and refreshes while you edit. Move it to the left, top, right, or bottom.

  2. Source

    Three languages, one file

    HTML, CSS, and JavaScript share the snippet. Add an external CSS or JavaScript library when a snippet needs one.

  3. Editor

    Theme, font, and keymap

    Pick a syntax theme and an editor font. Stay on the default keymap, or switch to Vim. Those choices stay with your account.

  4. Share

    Private, public, or embedded

    Keep a snippet to yourself, or publish it. Add tags, copy a link, open the full page, or embed the preview.

  5. Collections

    Group the ones that belong together

    A collection can stay private, or be open so anyone can view it.

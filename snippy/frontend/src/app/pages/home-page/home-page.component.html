Inside a snippet

The editor, the preview, and the way you share it all live on the same snippet.

  1. Preview

    It updates as you type

    The preview sits with the source and refreshes while you edit. Move it to the left, top, right, or bottom.

  2. Source

    Three languages, one file

    HTML, CSS, and JavaScript share the snippet. Add an external CSS or JavaScript library when a snippet needs one.

  3. Editor

    Theme, font, and keymap

    Pick a syntax theme and an editor font. Stay on the default keymap, or switch to Vim. Those choices stay with your account.

  4. Share

    Private, public, or embedded

    Keep a snippet to yourself, or publish it. Add tags, copy a link, open the full page, or embed the preview. An embed plays only while that snippet is public. Making it private stops the embed.

  5. Collections

    Group the ones that belong together

    A collection can stay private, or be open so anyone can view it.

A fork stands on its own

Forking copies the snippet. The original can disappear afterward.

  1. Copy

    Taken at the moment you fork

    HTML, CSS, JavaScript, and libraries are written onto the new snippet. Later edits stay on the snippet you change.

  2. Delete

    The original can go

    Deleting the original does not delete the fork. The credit keeps the original name and says the parent was deleted.

  3. Private

    The fork has its own setting

    Making the original private does not hide the fork. Each snippet is public or private on its own.
